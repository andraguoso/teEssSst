# teEssSst
game of questions from a catty soon-to-be friend

## description
Critter the cat wants to know you! He is a new acquaintance of yours, and he wants to be your friend. In order to do that,
he must know your likes and dislikes, whether you like school or not...
This game allows you to remember features of yourself you didn't remember, because it includes questions that not a lot of people ask (do they?).

## format
So far, it's structured as a form. I've thought of making it a Google Forms lookalike, but I also didn't want to lose the silly, homemade feel.
It starts with short questions (food, music options). The more you advance, the more specific the questions get. 

## process
Used HTML, CSS, vanilla JS. Very beginner level!
